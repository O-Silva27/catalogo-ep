🎨 CUSTOMIZAÇÕES ANTES DO DEPLOY

□ Logo customizada
   - Use o painel admin (engrenagem)
   - Recomendado 200x200px PNG
   - Será salvo no localStorage

□ Email WhatsApp correto
   - Procure por: wa.me/qr/
   - Coloque seu link correto

□ Credenciais admin alteradas
   - Email seu (não deixe a padrão)
   - Senha forte (mínimo 8 caracteres)

□ Produtos pré-cadastrados (opcional)
   - Adicione alguns no localhost primeiro
   - Use "exportar" para salvar
   - Depois "importar" no site online

⚡ PERFORMANCE

□ Imagens otimizadas
   - PNG: máx 500KB cada
   - JPG: máx 300KB cada
   - Recomendado: Compressor.io

□ Cache habilitado
   - Vercel faz automaticamente
   - Clientes veem página 0.5s mais rápida

□ CDN global
   - Vercel distribui automaticamente
   - Mundo inteiro acessa rápido

═══════════════════════════════════════════════════════════

🔒 PROTEÇÃO DE DADOS

□ localStorage seguro
   - Dados salvos no navegador do cliente
   - NÃO no servidor (privado!)
   - Cada dispositivo isolado

□ Sem roubo de dados
   - Você não armazena dados pessoais
   - Sem banco de dados externo
   - Tudo local no navegador

□ HTTPS automático
   - Todos os dados encriptados em trânsito
   - Certificado SSL grátis do Vercel

🆘 TROUBLESHOOTING

Se os produtos não aparecem:
□ Recarregue a página (Ctrl+F5)
□ Limpe cache (Ctrl+Shift+Delete)
□ Abra em modo privado/incógnito
□ Teste em outro navegador

Se o site carrega lento:
□ Comprime imagens
□ Reduz tamanho dos arquivos
□ Verifica WiFi/internet

Se login não funciona:
□ Verifica email/senha
□ Abre console (F12) e vê erros
□ Tenta modo privado
