PASSO 1: CRIAR CONTA GITHUB
─────────────────────────────────────────────────────────

1. Abra: https://github.com/signup

2. Preencha:
   ┌─────────────────────────────────┐
   │ Email: seu-email@gmail.com      │
   │ Password: sua-senha             │
   │ Username: seu-usuario           │
   └─────────────────────────────────┘

3. Clique em "Create account"

4. Confirme o email enviado

✅ Você agora tem conta GitHub!

═══════════════════════════════════════════════════════════

PASSO 2: CRIAR REPOSITÓRIO
─────────────────────────────────────────────────────────

1. Após logar, clique no "+" no canto superior direito

2. Clique em "New repository"

3. Preencha:
   ┌─────────────────────────────────┐
   │ Repository name: catalogo-ep    │
   │                                 │
   │ Description:                    │
   │ Catálogo Digital                │
   │ Estofados Providência           │
   │                                 │
   │ ○ Public (selecionado)          │
   │ ○ Private                       │
   │                                 │
   │ ☑ Add a README file             │
   └─────────────────────────────────┘

4. Clique em "Create repository"

✅ Repositório criado!

═══════════════════════════════════════════════════════════

PASSO 3: FAZER UPLOAD DOS ARQUIVOS
─────────────────────────────────────────────────────────

1. Na página do repositório, clique em "Add file"

2. Selecione "Upload files"

3. ARRASTE E SOLTE estes arquivos:
   
   ✓ catalogo-EP.html
   ✓ compartilhar-catalogo.html
   ✓ index.html
   ✓ package.json
   ✓ vercel.json
   ✓ .gitignore
   ✓ .vercelignore

4. Clique em "Commit changes"

✅ Arquivos no GitHub!

═══════════════════════════════════════════════════════════

PASSO 4: CRIAR CONTA VERCEL
─────────────────────────────────────────────────────────

1. Abra: https://vercel.com/signup

2. Clique em "Continue with GitHub"

3. Autorize o Vercel (aparece um popup)

4. Preencha dados básicos

✅ Conta Vercel criada!

═══════════════════════════════════════════════════════════

PASSO 5: FAZER DEPLOY
─────────────────────────────────────────────────────────

1. Na dashboard do Vercel, clique em "Add New Project"

2. Clique em "Import Project"

3. Procure por "catalogo-ep" e clique

4. Configurações:
   ┌──────────────────────────────────┐
   │ Framework Preset: Other          │
   │ Build Command: (deixa em branco) │
   │ Output Directory: .              │
   │ Environment Variables: (deixa)   │
   └──────────────────────────────────┘

5. Clique em "Deploy"

✅ DEPLOY INICIADO!
